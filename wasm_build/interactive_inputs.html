This page uses the same WebAssembly module from the project but calls parameterized wrappers so you can change vectors, scalars, and strides in real-time for DAXPY, DDOT, and DNRM2.

DAXPY

Calculates y = alpha * x + y. The vector y is updated within the WASM memory and returned in the result.

Use comma, space, or newline. For stride greater than 1, provide enough elements.

DDOT

Calculates the dot product x · y. The result returns a single double-precision value.

DNRM2

Calculates the Euclidean norm ||x||₂. Useful for validating vector magnitude and stride behavior.

Input Suggestions

  • Basic DAXPY: n=5, alpha=2, x=1,2,3,4,5, y=1,1,1,1,1. Expected result in y: 3,5,7,9,11.
  • DAXPY with negative values: n=4, alpha=-0.5, x=2,-4,6,-8, y=1,1,1,1. Good for checking signs and cancellation.
  • DAXPY with stride: n=3, incx=2, incy=2, x=1,99,2,99,3, y=4,77,5,77,6. Calculation only uses positions 0,2,4.
  • Classic DDOT: n=4, x=1,2,3,4, y=5,6,7,8. Expected result: 70.
  • Simple orthogonal DDOT: n=3, x=1,0,0, y=0,1,0. Expected result: 0.
  • DDOT with stride: n=3, incx=2, incy=2, x=1,99,2,99,3, y=4,77,5,77,6. Expected result: 32.
  • Standard DNRM2: n=3, x=2,6,3. Expected result: 7.
  • Pythagorean DNRM2: n=2, x=3,4. Expected result: 5.
  • DNRM2 with stride: n=2, incx=2, x=3,99,4. Expected result remains 5.
